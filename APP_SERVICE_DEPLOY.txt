STEP 2: DEPLOY BACKEND (5 minutes)
===================================

1. Login to Azure:
   az login

2. Create resource group (if you don't have one):
   az group create ^
     --name telecontrol-rg ^
     --location "brazilsouth"
   
   (Replace "brazilsouth" with YOUR region from Step 1)

3. Create App Service Plan:
   az appservice plan create ^
     --name telecontrol-plan ^
     --resource-group telecontrol-rg ^
     --location "brazilsouth" ^
     --is-linux ^
     --sku B1

4. Create Web App for Backend:
   az webapp create ^
     --resource-group telecontrol-rg ^
     --plan telecontrol-plan ^
     --name telecontrol-api-unique123 ^
     --deployment-container-image-name python:3.11-slim
   
   (Change "unique123" to something unique for you!)

5. Configure for Docker deployment:
   az webapp config container set ^
     --name telecontrol-api-unique123 ^
     --resource-group telecontrol-rg ^
     --docker-custom-image-name python:3.11-slim

6. Deploy your code:
   cd C:\Users\Interfocus\Desktop\UNIMAR\telecontrol
   az webapp up ^
     --name telecontrol-api-unique123 ^
     --resource-group telecontrol-rg ^
     --runtime "PYTHON:3.11"

7. Add environment variables:
   az webapp config appsettings set ^
     --name telecontrol-api-unique123 ^
     --resource-group telecontrol-rg ^
     --settings ^
       AZURE_OPENAI_API_KEY=your_key_here ^
       AZURE_OPENAI_ENDPOINT=your_endpoint_here ^
       AZURE_OPENAI_DEPLOYMENT_NAME=your_deployment_here


Your backend will be at:
https://telecontrol-api-unique123.azurewebsites.net


STEP 3: DEPLOY FRONTEND (5 minutes)
====================================

1. Build your Next.js app:
   cd telecon-ai
   npm run build

2. Create Web App for Frontend:
   az webapp create ^
     --resource-group telecontrol-rg ^
     --plan telecontrol-plan ^
     --name telecontrol-frontend-unique123 ^
     --runtime "NODE:20-lts"

3. Deploy frontend:
   az webapp up ^
     --name telecontrol-frontend-unique123 ^
     --resource-group telecontrol-rg ^
     --html

4. Add backend URL as environment variable:
   az webapp config appsettings set ^
     --name telecontrol-frontend-unique123 ^
     --resource-group telecontrol-rg ^
     --settings ^
       BACKEND_URL=https://telecontrol-api-unique123.azurewebsites.net


Your frontend will be at:
https://telecontrol-frontend-unique123.azurewebsites.net
