🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

  Issue: "Docker not found"
  → Solution: Install Docker Desktop
  → https://www.docker.com/products/docker-desktop

  Issue: "Azure CLI not installed"
  → Solution: Install Azure CLI
  → https://learn.microsoft.com/cli/azure/install-azure-cli

  Issue: "Script won't run"
  → Solution: Check file path, run as administrator
  → Try: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned

  Issue: "Deployment timeout"
  → Solution: Check internet connection, try again
  → Or use MANUAL_DEPLOYMENT_GUIDE.md

  Issue: "Services return 500 error"
  → Solution: Check logs with: az webapp log tail -g telecontrol-rg -n ...

  More issues? See QUICK_REFERENCE.md
