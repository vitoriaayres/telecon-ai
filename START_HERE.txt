🔍 WHAT'S HAPPENING UNDER THE HOOD
═══════════════════════════════════════════════════════════════════════════════

When you run DEPLOY_AZURE.bat, the script will:

   1. Verify all prerequisites (Docker, Node, Azure CLI)
   2. Authenticate with Azure
   3. Create resource group (telecontrol-rg)
   4. Create App Service plan (telecontrol-plan)
   5. Build Docker image for backend
   6. Push Docker image to Azure Container Registry
   7. Create backend Web App (telecontrol-api)
   8. Deploy FastAPI backend service
   9. Build Next.js frontend
   10. Create frontend Web App (telecontrol-web)
   11. Deploy frontend service
   12. Configure CORS and environment variables
   13. Run health checks
   14. Display final URLs

   Total: All automated in ~30-45 minutes
